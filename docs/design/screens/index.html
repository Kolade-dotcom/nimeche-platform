Fifteen screens

The public site, signing in, the member dashboard and the executive dashboard. Every file is self-contained and responsive — open one in a browser, or paste the whole thing into html.to.design to import it as a Figma frame.

The crest ships with these files as nimeche-logo.svg, in this same folder. Open any screen and you see it. If you paste a file into html.to.design instead of opening it, the image will not travel with the paste — build the crest once as a Figma component and drop it in, which is what you want in the Figma file anyway.
